Orchestra Surgical Display API

RB-Y1 수술로봇 상태를 Lenovo Y700 헤드 화면에 표시하는 읽기 전용 이벤트 API입니다. 로봇 제어 기능은 포함하지 않습니다.

API 0.3.0 정상 수신 HTTP 202 Lenovo 예시 10.77.0.11:8080
Python 연동 코드화면 전송은 로봇 동작과 분리되며, 연결이 잠시 끊기면 자동으로 다시 시도합니다.
로컬 검증python3 -m orchestra_surgical_display.simulator
